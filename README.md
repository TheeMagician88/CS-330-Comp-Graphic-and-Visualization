# CS-330 Computational Graphics and Visualization

## Project Overview

For my final project, I created a 3D recording studio scene using C++ and OpenGL. The scene includes studio speakers, a microphone, an audio interface, and a textured wooden surface. Throughout the course, I worked with shapes, transformations, camera controls, textures, and lighting to bring everything together.

## How do I approach designing software?

This project helped me learn how to take an idea and break it down into smaller pieces. I started with basic 3D shapes and worked on positioning them to create recognizable objects. I also learned how important textures and lighting are when designing a scene. Going forward, I can use this same approach to plan larger projects without getting overwhelmed by everything at once.

## How do I approach developing programs?

I learned to build and test my code in stages rather than trying to complete everything at once. Each milestone introduced something new, whether it was camera movement, textures, or lighting. I ran into a few challenges, especially when getting the lighting to work correctly, but troubleshooting those issues helped me better understand OpenGL. This course definitely helped me become more patient and organized when developing programs.

## How can computer science help me reach my goals?

As I continue working toward my computer science degree, I can see how these skills could be useful in game development, simulations, and interactive applications. Working with C++, OpenGL, and Visual Studio has helped strengthen my programming and problem-solving skills. Even if I don't pursue graphics development specifically, the experience of building a complete project from start to finish will help me in my future career.
